# Security policy

This repository is public. Commit configuration names, safe defaults, and infrastructure definitions; keep credentials in Azure Key Vault or local developer secret storage.

## Reporting a vulnerability

Use this repository's **Security > Advisories > Report a vulnerability** for private disclosure when available. Never include credentials, personal data, or exploit details in a public issue. If private reporting is unavailable, open an issue requesting a private contact without including sensitive details.

Security fixes target `main` and the latest deployed release. See [configuration security](docs/security.md) for authentication, permissions, rotation, and repository protections.
